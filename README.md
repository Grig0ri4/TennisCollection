Информационно-аналитическая система «Теннисная коллекция»
Данный программный продукт является объектом выпускной квалификационной работы (ВКР) по специальности 09.02.07 «Информационные системы и программирование». Система спроектирована для централизованного хранения, многофакторного анализа и персонализации статистических данных о профессиональных теннисных турнирах ассоциаций ATP и WTA.

## 1. Технологический стек (Stack)

Система реализована на базе актуальных технологий разработки корпоративного программного обеспечения:
Платформа: Windows 10/11 (.NET Framework 4.8)
Язык программирования: C#
Графический интерфейс: WPF (Windows Presentation Foundation)
Архитектурный паттерн: 3-Tier Architecture (Многоуровневая архитектура)
Система управления базами данных: PostgreSQL (провайдер Npgsql)
Визуализация и экспорт: LiveChartsCore, ClosedXML
Тестирование: MSTest (встроенный фреймворк Microsoft)

## 2. Архитектурные решения

Проект придерживается принципа разделения ответственности (Separation of Concerns):
Data Access Layer: Класс DatabaseHelper.cs полностью изолирует логику приложения от специфики работы с СУБД, обеспечивая безопасное выполнение параметризованных запросов.
Business Logic Layer: Классы-менеджеры (AdminFinalsManager и др.) инкапсулируют бизнес-правила, включая строгую валидацию вводимых данных через регулярные выражения.
Presentation Layer: XAML-страницы реализуют адаптивный интерфейс с динамическим обновлением коллекций (DataGrid) и интерактивных компонентов.
Configuration Layer: Файл App.config централизованно хранит строку подключения к облачной базе данных и конфигурации зависимостей.

## 3. Ключевые функциональные модули

3.1. Модуль аналитики и визуализации
Интеграция с библиотекой LiveChartsCore позволяет строить интерактивные круговые и столбчатые диаграммы, динамически пересчитывая агрегированные SQL-данные по годам и типам турниров.
3.2. Персональный дневник просмотров
Реализован механизм сохранения матчей в личный профиль с возможностью выставления качественных оценок (от 1 до 10) и фиксации персональных текстовых заметок.
3.3. Модуль экспорта
Алгоритмы приложения позволяют выгружать сформированную статистику игроков во внешние электронные таблицы формата .xlsx с помощью ClosedXML для последующей независимой аналитики.
3.4. Администрирование и защита данных
Реализована ролевая модель доступа. Панель администратора оснащена защитой от некорректного ввода счёта (Regex) и перехватчиком системных ошибок при нарушении ссылочной целостности базы данных.

## 4. Информационная безопасность и автономность

Криптография: Пароли пользователей не хранятся в открытом виде, а обрабатываются криптографическим алгоритмом SHA-256 на этапе авторизации и регистрации.
Защита базы данных: Приложение устойчиво к SQL-инъекциям за счет полного отказа от конкатенации строк в пользу параметризованных запросов. База данных вынесена в облачное хранилище, что освобождает клиента от необходимости локального развертывания СУБД.

## 5. Инструкция по развертыванию

Вариант 1: Для пользователей (Готовый исполняемый файл)
Распакуйте архив с программой в любую удобную директорию. Убедитесь, что рядом с исполняемым файлом TennisCatalog.exe находятся все необходимые .dll библиотеки (Npgsql, LiveCharts, ClosedXML).
Запустите исполняемый файл TennisCatalog.exe.
Ознакомьтесь и примите условия Лицензионного соглашения конечного пользователя (EULA).
Программа автоматически подключится к облачной базе данных (требуется интернет-соединение).
Вариант 2: Для разработчиков (Запуск из исходного кода)
Требование: на компьютере должна быть установлена среда Microsoft Visual Studio 2022.
Клонируйте репозиторий проекта или распакуйте исходный код.
Откройте файл решения TennisCatalog.sln.
Дождитесь автоматического восстановления пакетов NuGet.
Запустите проект (клавиша F5).
